# Pharmadesk 💊

**Pharmacy Management System - Sab Kuch Ek Jagah**

Modern pharmacy ka complete solution. Inventory se leke billing tak, sab ek dashboard me.

## ✨ Features

- **💊 Inventory** - Stock manage karo, expiry track karo
- **🧾 Billing** - Fast billing + GST invoice  
- **📊 Reports** - Sales & profit reports dekho

## 🚀 Tech Stack

- **Framework:** Next.js 14 App Router
- **Styling:** Tailwind CSS
- **Language:** TypeScript
